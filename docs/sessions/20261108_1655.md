## 项目概况
- 用法：浏览器或安卓上按住说话，后端用 WebSocket 代理阿里云 DashScope 实时转写，结果写进 Markdown 文稿；「整理」调用 OpenAI 兼容大模型把口语稿整理成书面 Markdown；安卓端可以把转写结果推到 Mac 光标处（发送到电脑），Mac 端是菜单栏应用。
- 技术栈：后端 Go + SQLite + coder/websocket；前端 Vite + React + CodeMirror 6；安卓用 Jetpack Compose（android/）；Mac 是 Swift Package（mac/，bundle ID top.onlyquant.tingxie.mac）。
- 线上地址 https://tingxie.onlyquant.top。服务端、安卓、Mac 正式版都是 0.8.0（最新标签 v0.8.0），Eric 已部署。

## 开发环境（Mac）
- .tmp 下有 venv（playwright、pillow、websockets）、asr-dev、devtool、frontend node_modules。截图工具：.tmp/shots/shoot.py（参数：文件路径 宽x高 输出前缀 锚点…）。.tmp/backanim/ 下有这次的脚本：run.py、fwd.py 用 Playwright 点原型的返回/进入按钮检查动画；measure.py 从安卓截图量勾选框和第一行文字的中心差。
- 开发后端：先 `task build:frontend`，再 `go build -o .tmp/asr-dev ./cmd/asr`，然后用 Bash 的 run_in_background 执行 `set -a; . ./.env; set +a; exec .tmp/asr-dev -config .tmp/dev.yaml > .tmp/asr-dev.log 2>&1`。端口 36750，dev_user 模式，curl http://127.0.0.1:36750/api/... 不用带 token。建文稿 POST /api/documents {"title"}，改内容 PATCH /api/documents/<id> {"content": ...}。
- 安卓模拟器（AVD Medium_Phone，安卓 16，density 420）：用 run_in_background 跑 `~/Library/Android/sdk/emulator/emulator -avd Medium_Phone -no-snapshot-save -no-audio`；adb 在 ~/Library/Android/sdk/platform-tools（Bash 里要自己加 PATH）。应用已登录开发服务。构建安装：`export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"; cd android && ./gradlew installDebug`。en0 没有 IP，Mac 局域网 IP 在 en1。截动画中途：`adb shell settings put global animator_duration_scale 10`（Compose 也跟着变慢）；模拟手势用 `adb shell input motionevent DOWN/MOVE/UP`；改字体缩放用 `settings put system font_scale`。测完把 animator_duration_scale、http_proxy 删掉（原来都是 null），font_scale 改回 1.0，深色模式 `cmd uimode night no`。停模拟器 `adb emu kill`。
- Mac 客户端：`task build:mac` / `task run:mac` / `task test:mac`。开发前先退出正式版，必须用 `open` 启动。连本地服务用 `defaults write top.onlyquant.tingxie.mac server http://127.0.0.1:36750`，测完要改回来。
- 编辑器的坑：CodeMirror 开了自动换行，Home/End 按坐标找行边界，脱离文本流的装饰会影响结果；CodeMirror 主题样式走 adoptedStyleSheets。Playwright 在 macOS 上用 Meta+ArrowDown 跳到文末。
