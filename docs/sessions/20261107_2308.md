## 项目概况
- 用法：浏览器或安卓上按住说话，后端用 WebSocket 代理阿里云 DashScope 实时转写，结果写进 Markdown 文稿；「整理」调用 OpenAI 兼容大模型把口语稿整理成书面 Markdown；安卓端可以把转写结果推到 Mac 光标处（发送到电脑），Mac 端是菜单栏应用。
- 后端 Go + SQLite + coder/websocket；前端 Vite + React；安卓 Jetpack Compose（android/）；Mac 是 Swift Package（mac/，bundle ID top.onlyquant.tingxie.mac，macOS 13+）。
- 线上 https://tingxie.onlyquant.top，Authelia client ID 是 tingxie。线上服务端和正式版 Mac 客户端（/Applications/TingXie.app）都是 0.7.0。

## 开发环境（Mac）
- .tmp 下有 venv（playwright、pillow、websockets）、asr-dev、devtool、frontend node_modules；.tmp/shots/shoot.py 可以给原型的各个锚点截图（参数：文件路径 宽x高 输出前缀 锚点…）。
- 开发后端：先 `task build:frontend`，再 `go build -o .tmp/asr-dev ./cmd/asr`；然后用 Bash 的 run_in_background 执行 `set -a; . ./.env; set +a; exec .tmp/asr-dev -config .tmp/dev.yaml > .tmp/asr-dev.log 2>&1`。端口 36750，dev_user 模式，监听所有网卡。
- 调接口：dev_user 模式下 curl http://127.0.0.1:36750/api/... 不用带 token；`.tmp/devtool/devtool send|mac|login` 可以模拟手机、Mac 和设备登录。
- 安卓模拟器（AVD Medium_Phone）：流量会走 Mac 上的代理，10.0.2.2 和 adb reverse 都会 502。服务器地址填 Mac 的局域网 IP（`ipconfig getifaddr en0`）加 :36750。dev_user 模式的设备登录直接到确认页，点「允许」即可。模拟器里的应用现在就登录在开发服务上。adb 在 ~/Library/Android/sdk/platform-tools（Bash 里要自己加 PATH），可以用 uiautomator dump 找控件坐标、screencap 截图，debug 包可以用 run-as 读写 files/。
- 安卓构建：`export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"; cd android && ./gradlew installDebug`。
- Mac 客户端：`task build:mac` / `task run:mac` / `task test:mac`。开发前先退出正式版；必须用 `open` 启动。连本地服务用 `defaults write top.onlyquant.tingxie.mac server http://127.0.0.1:36750`，测完要改回来。
