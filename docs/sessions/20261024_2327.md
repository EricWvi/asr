## 项目概况
- 手机/PC 浏览器按住说话 → 后端 WebSocket 代理阿里云 DashScope `qwen-audio-3.1-asr-flash-message`（边说边出字）→ 转写结果插入 CodeMirror 6 文稿的光标处；「整理」按钮调用 OpenAI 兼容大模型（默认 DeepSeek `deepseek-flash`）把口语稿整理成书面 Markdown。安卓（Compose）和 Mac（Swift 菜单栏）客户端在后面阶段。
- 技术栈：Go + SQLite（modernc，无 cgo）+ vite + React 19 + Tailwind 4 + shadcn（radix-ui）+ React Query + zustand，中文界面。OIDC 照搬 ../homepage。
- 设计以 design/pc.html 原型为准（URL 锚点可直接看各状态：#dark #voice #rec #menu #rename #toast #colors #scrolled #only-sky 等，可组合）。token 在 frontend/src/index.css（.tint-<颜色> 类派生 fill/deep/sel/mark，暗色走 prefers-color-scheme）。
