## 项目概况
- 用法：手机或电脑浏览器里按住说话，后端用 WebSocket 代理阿里云 DashScope 的 qwen-audio-3.1-asr-flash-message，边说边出字，结果插到 CodeMirror 6 文稿的光标处。「整理」按钮调用 OpenAI 兼容的大模型（默认 DeepSeek deepseek-flash），把口语稿整理成书面 Markdown。安卓端还能把转写结果推到 Mac 的光标处（「发送到电脑」）。
- 技术栈：
  - 后端：Go + SQLite（modernc，带 FTS5）+ coder/websocket；
  - 前端：Vite + React 19 + Tailwind 4 + shadcn（radix-ui）+ React Query + zustand，中文界面。
- 原型：网页端以 design/pc.html 为准，设备授权确认页是 design/device-auth.html，安卓端是 design/android.html。界面 token 在 frontend/src/index.css。
- 线上：https://tingxie.onlyquant.top，运行镜像 ghcr.io/ericwvi/asr:0.1.0。Authelia 的 client ID 是 tingxie，安卓和 Mac 客户端的登录也走这个 client。
