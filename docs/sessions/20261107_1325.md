## 项目概况
- 用法：浏览器或安卓上按住说话，后端用 WebSocket 代理阿里云 DashScope 实时转写，结果写进 Markdown 文稿；「整理」调用 OpenAI 兼容大模型（默认 DeepSeek deepseek-flash）把口语稿整理成书面 Markdown；安卓端还能把转写结果推到 Mac 光标处（发送到电脑）。
- 后端 Go + SQLite（modernc，FTS5）+ coder/websocket；前端 Vite + React 19 + Tailwind 4 + shadcn + React Query + zustand。
- 线上 https://tingxie.onlyquant.top，Authelia client ID 是 tingxie，安卓和 Mac 客户端也走它。上一个 tag v0.5.1（2026-11-06）。

## 开发环境（Mac）
- 已就绪：.tmp 下 venv（playwright、pillow、websockets）、asr-dev、devtool、frontend node_modules；Android Studio、SDK、adb、AVD Medium_Phone；Gradle 发行版在 .tmp/gradle。模拟器图库里有测试图 sunset.jpg。
- 安卓构建：`export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"; cd android && ./gradlew installDebug`（单元测试 `./gradlew testDebugUnitTest`，离线可加 --offline）。
- 开发后端：Bash 的 run_in_background 执行 `set -a; . ./.env; set +a; exec .tmp/asr-dev -config .tmp/dev.yaml > .tmp/asr-dev.log 2>&1`，:36750，dev_user 模式；后端改了要重新 `go build -o .tmp/asr-dev ./cmd/asr`。
- 调接口：`T=$(cat .tmp/devtool/phone.token)`，`curl -H "Authorization: Bearer $T" http://127.0.0.1:36750/api/...`。token 过期就用 `.tmp/devtool/devtool login android 名字 > .tmp/devtool/phone.token` 重新发。
- 模拟 Mac：`.tmp/devtool/devtool mac "$(cat .tmp/devtool/mac.token)"`（run_in_background，输出 connected 即在线）；token 过期用 `.tmp/devtool/devtool login mac 名字 > .tmp/devtool/mac.token`。`devtool send TOKEN 文字 [设备id]` 可以发推送。
- 模拟器：run_in_background 执行 `~/Library/Android/sdk/emulator/emulator -avd Medium_Phone -no-window -no-audio -no-boot-anim -gpu swiftshader_indirect`，等 `adb shell getprop sys.boot_completed` 为 1。app 里服务器是 http://10.0.2.2:36750（登录状态已保存）。截图：`.tmp/venv/bin/python .tmp/android-tools/shot.py 名字`，输出 .tmp/shots/app/名字.png（宽 412，乘 2.621 得到 adb input 坐标；列表右上角头像约 993,220，头像菜单项依次在 y≈350/480/606/735）。暗色：`adb shell cmd uimode night yes|no`。假麦克风：`adb push .tmp/asr-probe/input.wav /data/local/tmp/in.wav && adb shell run-as top.onlyquant.tingxie cp /data/local/tmp/in.wav files/fake-mic.wav && adb shell pm grant top.onlyquant.tingxie android.permission.RECORD_AUDIO`，然后 `adb shell input swipe x y x y 9000` 模拟按住。重装后应用会打开上次的文稿。关模拟器用 `adb emu kill`。
