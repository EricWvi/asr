## 项目概况
- 手机/PC 浏览器按住说话 → 后端 WebSocket 代理阿里云 DashScope `qwen-audio-3.1-asr-flash-message`（边说边出字）→ 转写结果插入 CodeMirror 6 文稿的光标处；「整理」按钮调用 OpenAI 兼容大模型（默认 DeepSeek `deepseek-flash`）把口语稿整理成书面 Markdown。安卓（Compose）和 Mac（Swift 菜单栏）客户端在后面阶段。
- 技术栈：Go + SQLite（modernc，无 cgo，内置 SQLite 3.53，带 FTS5）+ coder/websocket；vite + React 19 + Tailwind 4 + shadcn（radix-ui）+ React Query + zustand，中文界面。OIDC 照搬 ../homepage。
- 设计以 design/pc.html 原型为准。右下角有原型专用的「状态」菜单，列出全部锚点（语音、整理、搜索、光标行等状态，带暗色开关），也可以直接用 URL 锚点打开，例如 #tidying、#search-hit、#dark-rec。token 在 frontend/src/index.css。

## 注意事项
- 不要打印 .env、配置值或可能含密钥的环境变量；Go 配置测试在 write() 里清空了 ASR_* 变量，新增测试也要这样隔离。
- 停服务用 `pgrep -x <名字>` + `kill <pid>`；不要用 `pkill -f`/`pgrep -f` 带命令片段，会匹配到当前 shell 自己。
- coder/websocket 的 Read/Write 在 ctx 取消时会直接关闭连接；出错后还要发消息的话，读写用不随出错取消的 ctx（参考 internal/server/asr.go 的 pumpAudio）。
- Authelia 契约测试 testdata 里的哈希对应明文 homepage-test-password / homepage-test-client-secret，不要改。
- 前端 tsconfig 开了 noUncheckedIndexedAccess，数组和正则分组取值要处理 undefined。
- 始终用简体中文和 Eric 交流；临时文件和依赖放 .tmp；不要在本地构建 Docker 镜像；只在 Eric 要求时提交，默认提交到当前分支，推送前先问；有不确定的产品决策先问 Eric，给出推荐；界面改动先改原型，亮色、暗色都要检查，新状态加进原型右下角的状态菜单。
- memories 是独立的嵌套 Git 仓库；更新记忆后，Eric 说「持久化」时再提交并 fetch/rebase/push。
