## 项目概况
- 用法：手机或电脑浏览器里按住说话，后端用 WebSocket 代理阿里云 DashScope 的 qwen-audio-3.1-asr-flash-message，边说边出字，结果插到 CodeMirror 6 文稿的光标处。「整理」按钮调用 OpenAI 兼容的大模型（默认 DeepSeek deepseek-flash），把口语稿整理成书面 Markdown。
- 技术栈：Go + SQLite（modernc，带 FTS5）+ coder/websocket；前端是 Vite + React 19 + Tailwind 4 + shadcn（radix-ui）+ React Query + zustand，中文界面。OIDC 照搬 ../homepage。
- 原型：网页端以 design/pc.html 为准，设备授权确认页的原型是 design/device-auth.html。右下角有原型专用的「状态」菜单，列出全部锚点并带暗色开关；也可以直接用 URL 锚点打开，例如 #profile、#avatar-crop、#devices、#tidying、#dark-search-hit。界面 token 在 frontend/src/index.css。
