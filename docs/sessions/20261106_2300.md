## 项目概况
- 用法：浏览器或安卓上按住说话，后端用 WebSocket 代理阿里云 DashScope 实时转写，结果写进 Markdown 文稿；「整理」调用 OpenAI 兼容大模型（默认 DeepSeek deepseek-flash）把口语稿整理成书面 Markdown；安卓端还能把转写结果推到 Mac 光标处（发送到电脑）。
- 后端 Go + SQLite（modernc，FTS5）+ coder/websocket；前端 Vite + React 19 + Tailwind 4 + shadcn + React Query + zustand。
- 线上 https://tingxie.onlyquant.top，Authelia client ID 是 tingxie，安卓和 Mac 客户端也走它。上一个 tag v0.3.0。

- 安卓构建：`export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"; cd android && ./gradlew installDebug`（单元测试 `./gradlew testDebugUnitTest`）。
- ASR 协议测试：`TINGXIE_TOKEN=$(cat ../.tmp/devtool/phone.token) TINGXIE_WAV=$PWD/../.tmp/asr-probe/input.wav ./gradlew testDebugUnitTest --tests '*AsrSocketTest*' -i`（需要开发后端在跑）。token 过期就用 `.tmp/devtool/devtool login android 名字 > .tmp/devtool/phone.token` 重新发。
- 开发后端：Bash 的 run_in_background 执行 `set -a; . ./.env; set +a; exec .tmp/asr-dev -config .tmp/dev.yaml`，:36750，dev_user 模式；后端改了要重新 go build -o .tmp/asr-dev ./cmd/asr。
- 模拟器：run_in_background 执行 `~/Library/Android/sdk/emulator/emulator -avd Medium_Phone -no-window -no-audio -no-boot-anim -gpu swiftshader_indirect`，等 `adb shell getprop sys.boot_completed` 为 1。app 里服务器填 http://10.0.2.2:36750（登录状态已保存在模拟器上）。截图：`.tmp/venv/bin/python .tmp/android-tools/shot.py 名字`，输出 .tmp/shots/app/名字.png（宽 412，乘 2.621 得到 adb input 的像素坐标）。暗色：`adb shell cmd uimode night yes|no`。假麦克风：`adb push .tmp/asr-probe/input.wav /data/local/tmp/in.wav && adb shell run-as top.onlyquant.tingxie cp /data/local/tmp/in.wav files/fake-mic.wav && adb shell pm grant top.onlyquant.tingxie android.permission.RECORD_AUDIO`，然后 `adb shell input swipe x y x y 9000` 模拟按住。关模拟器用 `adb emu kill`。
