## 项目概况
- 用法：浏览器或安卓上按住说话，后端用 WebSocket 代理阿里云 DashScope 实时转写，结果写进 Markdown 文稿；「整理」调用 OpenAI 兼容大模型把口语稿整理成书面 Markdown；安卓端可以把转写结果推到 Mac 光标处（发送到电脑），Mac 端是菜单栏应用。
- 技术栈：后端 Go + SQLite + coder/websocket；前端 Vite + React + CodeMirror 6（实时预览在 frontend/src/editor/live-preview.ts，样式在 frontend/src/index.css）；安卓用 Jetpack Compose（android/）；Mac 是 Swift Package（mac/，bundle ID top.onlyquant.tingxie.mac）。
- 线上地址 https://tingxie.onlyquant.top。服务端、安卓、Mac 正式版都是 0.8.0，Eric 已部署并验证（2026-11-08），记忆已同步。

## 开发环境（Mac）
- .tmp 下有 venv（playwright、pillow、websockets）、asr-dev、devtool、frontend node_modules。截图工具：.tmp/shots/shoot.py（参数：文件路径 宽x高 输出前缀 锚点…）。.tmp/endkey/ 下有这次用的 Playwright 脚本：repro.py 用 11 个用例检查 End 键，look.py 截引用列表亮暗色，可以照着写编辑器的回归检查。
- 开发后端：先 `task build:frontend`，再 `go build -o .tmp/asr-dev ./cmd/asr`，然后用 Bash 的 run_in_background 执行 `set -a; . ./.env; set +a; exec .tmp/asr-dev -config .tmp/dev.yaml > .tmp/asr-dev.log 2>&1`。端口 36750，dev_user 模式，curl http://127.0.0.1:36750/api/... 不用带 token。改文稿内容用 PATCH /api/documents/<id> {"content": ...}。前端嵌在二进制里，改了前端要重新构建两步并重启。
- 编辑器的坑：CodeMirror 开了自动换行，Home/End 按坐标找行边界，脱离文本流的装饰会影响结果；replace 装饰不会被 mark 包住；.cm-content 是 plaintext-only 可编辑区域，white-space 会被强制保留空白。CodeMirror 的主题样式走 adoptedStyleSheets，document.styleSheets 里查不到。Playwright 在 macOS 上用 Meta+ArrowDown 跳到文末，Control+End 不行。
- 安卓模拟器（AVD Medium_Phone）：服务器地址填 Mac 的局域网 IP（`ipconfig getifaddr en0`）加 :36750。adb 在 ~/Library/Android/sdk/platform-tools（Bash 里要自己加 PATH）。安卓构建：`export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"; cd android && ./gradlew installDebug`。
- Mac 客户端：`task build:mac` / `task run:mac` / `task test:mac`。开发前先退出正式版，必须用 `open` 启动。连本地服务用 `defaults write top.onlyquant.tingxie.mac server http://127.0.0.1:36750`，测完要改回来。
