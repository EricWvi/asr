## 项目是什么
一个 ASR 服务，用户之间用 OIDC 隔离。OIDC 部分完全照搬 ../homepage 的代码。注意：homepage 只用来参考 OIDC，配色等设计 token 不要沿用它的。
- 手机浏览器或安卓客户端录音，后端调用 qwen-audio-3.1-asr-flash-message 转成文字。
- 两种模式：
  1. 发送到电脑：文字直接插入 Mac 客户端的光标处。已决定只放在安卓客户端，网页里不做。
  2. 浏览器里的语音笔记：可以有多份文稿，标题默认是本地时间字符串。按住按钮说话，转写结果追加到文稿里；换行按钮会另起一行。
- 「整理」按钮调用 DeepSeek API 整理文稿，只在语音模式下出现。
- 前端要同时适配 PC 宽屏和手机。可以用 service worker，但不要出现 PWA 安装提示。
- 编辑器用 CodeMirror 6 单栏编辑，不做分屏预览。不要用 tiptap 这类富文本方案。要支持 Markdown 快捷输入，比如输入 `## ` 立即变成二级标题、`- ` 变成列表，以及可点击的待办勾选框。

## 已完成
PC 网页原型已提交：design/pc.html，提交 81a8f9e。这是一个单 HTML 静态原型，正文不可编辑。用浏览器打开就能看，地址后加锚点可以直接进入某个状态，多个锚点用 - 连接组合：
- #dark、#voice、#rec、#colors、#scrolled、#listdown、#menu、#select
- #only-<颜色>：侧栏只显示该颜色的文稿
- 颜色名（butter / peach / rose / periwinkle / sky / mint）：打开第一份该颜色的文稿

原型中已经确定的设计，实现时照这个来：
- 风格参考 Craft：暖白页面底 #faf8f5，大圆角，柔和的弥散阴影，交互强调色是蓝 #1a7cf5，录音中用红色。应用整体最大宽 1440px，纸面最大宽 880px，正文宽 760px。
- 纸面所有文稿统一用米黄（奶油黄按 10% 混白）。各文稿用不同颜色铺底的方案 Eric 已经否决，只有黄色看着舒服。暗色模式下纸面接近中性。
- 吸顶栏：纸面内的实色底，滚动后左侧显示标题（15px、半粗），下方出现中性灰细线加淡阴影。不用彩色线，不用渐变遮罩。
- 吸顶栏右侧只有「键盘 语音」两个按钮：32px 高、8px 圆角、无底色，当前模式用浅灰底。默认是键盘模式。
- 语音模式的底部悬浮条从左到右是：整理 ｜ 按住 空格 说话（蓝色）｜ 换行。
- 每份文稿有一个粉彩颜色，新建时从六种里随机，用户可以在标题下方的小圆点里自选。颜色派生出几种用法：
  - fill：侧栏色块、筛选色点
  - deep：加深版，给 Markdown 标记符号和刚转写的下划线着色
  - sel：选中文字背景，半透明
  - mark：==高亮== 的背景，实色
  刚转写的文字显示 2px 深色下划线，约 2.5 秒后淡出。
- 侧栏：「文稿」标题行右侧有六个色点，点一下只看该颜色，再点一下取消。文稿按日期分组，分组标题吸顶。列表隐藏滚动条，还能往下滚时底部渐隐。左下角是用户行，没有分隔线，悬停时出现浅底。
- 「更多」操作放在侧栏文稿的右键菜单里：重命名、复制 Markdown、导出 .md，分隔线后是删除（红色，放最后）。
- 正文区不显示滚动条。

## 实现时与原型不同的地方
原型里所有 Markdown 标记符号（##、-、**、==、>、反引号）一直显示，标题的 # 挂在左侧页边外。实际实现改成用 CodeMirror 6 的 decoration 做实时预览：光标所在行显示源码，标记符号按原型样式用文稿深色显示；其他行隐藏标记符号，只显示渲染后的效果。
