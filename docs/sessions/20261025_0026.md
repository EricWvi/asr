## 项目概况
- 手机/PC 浏览器按住说话 → 后端 WebSocket 代理阿里云 DashScope `qwen-audio-3.1-asr-flash-message`（边说边出字）→ 转写结果插入 CodeMirror 6 文稿的光标处；「整理」按钮调用 OpenAI 兼容大模型（默认 DeepSeek `deepseek-flash`）把口语稿整理成书面 Markdown。安卓（Compose）和 Mac（Swift 菜单栏）客户端在后面阶段。
- 技术栈：Go + SQLite（modernc，无 cgo）+ vite + React 19 + Tailwind 4 + shadcn（radix-ui）+ React Query + zustand，中文界面。OIDC 照搬 ../homepage。
- 设计以 design/pc.html 原型为准（URL 锚点可直接看各状态：#dark #voice #rec #menu #rename #toast #colors #scrolled #only-sky #source，以及光标行状态 #at-mark/li/task/quote/hr/code/table/img，可组合；正文里点任意一行可移动光标）。token 在 frontend/src/index.css（.tint-<颜色> 类派生 fill/deep/sel/mark，暗色走 prefers-color-scheme）。

## 注意事项
- 不要打印 .env、配置值或可能含密钥的环境变量；Go 配置测试已在 write() 里清空 ASR_* 变量，新增测试也要这样隔离。

- Authelia 契约测试 testdata 里的哈希对应明文 homepage-test-password / homepage-test-client-secret，不要改这两个明文。
- 前端 tsconfig 开了 noUncheckedIndexedAccess，数组和正则分组取值要处理 undefined。
