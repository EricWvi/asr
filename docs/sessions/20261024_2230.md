## 项目概况
- 手机/PC 浏览器按住说话 → 后端 WebSocket 代理阿里云 DashScope `qwen-audio-3.1-asr-flash-message`（/api-ws/v1/inference duplex，边说边出字）→ 转写结果插入 CodeMirror 6 文稿的光标处；「整理」按钮调用 OpenAI 兼容的大模型（默认 DeepSeek `deepseek-flash`）把口语稿整理成规范书面 Markdown。安卓客户端（Compose）和 Mac 客户端（Swift 菜单栏）在后面的阶段。
- 技术栈：Go + SQLite（modernc，无 cgo）+ vite + React 19 + Tailwind 4 + shadcn + React Query + zustand，中文界面。OIDC 照搬 ../homepage（只参考 OIDC 和工程结构，配色等设计 token 不用 homepage 的）。
- 设计以 design/pc.html 原型为准（URL 锚点如 #dark、#voice、#rec、#menu 可直接看各状态）。token 已搬进 frontend/src/index.css：暖白底 #faf8f5、纸面统一米黄、蓝 #1a7cf5 交互、红录音、六种文稿粉彩及 fill/deep/sel/mark 派生（.tint-<颜色> 类）。实现与原型的区别：用 CM6 decoration 做实时预览——光标所在行显示源码（标记符号用文稿 deep 色），其他行隐藏标记符号。
