## 项目概况
- 用法：浏览器或安卓上按住说话，后端用 WebSocket 代理阿里云 DashScope 实时转写，结果写进 Markdown 文稿；「整理」调用 OpenAI 兼容大模型把口语稿整理成书面 Markdown；安卓端可以把转写结果推到 Mac 光标处（发送到电脑），Mac 端是菜单栏应用。
- 后端 Go + SQLite + coder/websocket；前端 Vite + React；安卓 Jetpack Compose（android/）；Mac 是 Swift Package（mac/，bundle ID top.onlyquant.tingxie.mac，macOS 13+）。
- 线上 https://tingxie.onlyquant.top，Authelia client ID 是 tingxie。Eric 已部署服务端 0.7.0，并装好正式版 Mac 客户端（/Applications/TingXie.app），都测试过。

## 开发环境（Mac）
- .tmp 下有 venv（playwright、pillow、websockets）、asr-dev、devtool、frontend node_modules；Xcode 27.1 / Swift 6.4；Android Studio、SDK、AVD Medium_Phone，adb 在 ~/Library/Android/sdk/platform-tools（Bash 里要自己加 PATH）。
- 开发后端：Bash 的 run_in_background 执行 `set -a; . ./.env; set +a; exec .tmp/asr-dev -config .tmp/dev.yaml > .tmp/asr-dev.log 2>&1`，端口 36750，dev_user 模式；后端改了要重新 `go build -o .tmp/asr-dev ./cmd/asr`。
- 调接口：`T=$(cat .tmp/devtool/phone.token)`，`curl -H "Authorization: Bearer $T" http://127.0.0.1:36750/api/...`；`.tmp/devtool/devtool send TOKEN 文字 [设备id]` 模拟手机发送，`devtool mac TOKEN` 模拟 Mac，`devtool login mac|android 名字` 重发 token。
- Mac 客户端：`task build:mac` 打包 mac/build/TingXie.app（VERSION、UNIVERSAL=1、MAC_SIGN_IDENTITY；钥匙串里有证书时默认用它），`task run:mac` 打包并打开，`task test:mac` 单元测试（已并入 task test）。开发时先退出 /Applications 里的正式版；开发版和正式版共用设置，连本地服务用 `defaults write top.onlyquant.tingxie.mac server http://127.0.0.1:36750`，测完要在菜单里改回 tingxie.onlyquant.top。必须用 `open` 启动（直接跑可执行文件，辅助功能权限会算到 VS Code 头上）；`open --env TINGXIE_DEMO=1 mac/build/TingXie.app` 会填入示例记录并自动打开菜单，配合 `screencapture -x` 截图（已授予屏幕录制权限）。日志：`/usr/bin/log show --info --predicate 'subsystem == "top.onlyquant.tingxie.mac"' --last 5m`。
- 测插入前先 `pbpaste > .tmp/wsprobe/clip.bak` 暂存 Eric 的剪贴板，测完还原。
- 安卓构建：`export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"; cd android && ./gradlew installDebug`；安卓签名密钥在 ~/.android/tingxie-release.jks，密码在同目录 tingxie-release.env（不要打印）。
