# GFM 样例文稿

这份文稿覆盖「听写」支持的全部 Markdown 写法：GFM 加 ==高亮==。Web 编辑器和安卓端都拿它对照渲染结果。

## 行内样式

普通文字里可以有**粗体**、*斜体*、***粗斜体***、~~删除线~~、==高亮==和`行内代码`。

样式可以嵌套：**粗体里的==高亮==**，==高亮里的*斜体*==，~~删除线里的`代码`~~。

中文标点旁边也要能识别：「**引号里的粗体**」，结尾是粗体的句子**像这样**。

转义的符号原样显示：\*不是斜体\*，\==不是高亮\==，\`不是代码\`。

  - [x] 嵌套的已完成待办
