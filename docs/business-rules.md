# 业务规则

本文描述「听写」的业务概念与规则，不涉及实现方式。标注「规划中」的部分尚未实现。

## 概念

| 概念 | 说明 |
| --- | --- |
| 用户 | 通过统一认证（Authelia）登录的人。每个用户拥有一套独立的文稿。 |
| 文稿 | 一篇 Markdown 笔记，有标题、颜色和正文。 |
| 图片 | 粘贴或拖进文稿的图片，属于上传它的用户。 |
| 文稿颜色 | 六种粉彩之一：奶油黄、桃、玫瑰、长春花、天空、薄荷。用来在侧栏区分文稿，也决定标记符号、选中文字和高亮的颜色。 |
| 键盘模式 | 用键盘编辑文稿的默认模式。 |
| 语音模式 | 按住按钮说话，转写结果插入文稿的模式。 |
| 转写 | 一次按住说话得到的文字。 |
| 整理 | 把口语转写稿梳理成规范的书面 Markdown。 |
| 设备 | 登录过的安卓或 Mac 客户端。 |

## 用户与登录

- 只有登录后才能查看和修改内容。未登录时打开页面会自动跳转到统一认证登录。
- 同一个人在统一认证中的账号始终对应同一个用户；在统一认证里修改显示名或邮箱，不影响已有数据，下次登录时显示名会随之更新。
- 用户之间的数据完全隔离：看不到、也改不了别人的文稿。
- **登录状态永久有效**：登录后无论多久不访问，都不需要重新登录，直到用户手动退出。
- **退出登录**：
  - 只退出当前浏览器，其他设备或浏览器上的登录不受影响。
  - 退出后停在“已退出登录”页面，不会自动重新登录；点击“登录”才会重新进入统一认证。
  - 退出不会退出统一认证本身，若统一认证仍处于登录状态，再次登录可能无需输入密码。
- 离线时无法退出登录。

## 个人资料

- 用户菜单里的「个人资料」显示头像、显示名和邮箱。显示名和邮箱来自统一认证，在这里不能修改。
- 没有头像时显示显示名的首字母。
- 更换头像：选一张 PNG、JPEG、GIF 或 WebP 图片，在圆形取景框里拖动、缩放后保存，保存的是取景框里的部分。GIF 只取第一帧。
- 可以移除头像，恢复显示首字母。
- 头像显示在侧栏和设备登录的确认页，只有本人能看到。

## 文稿

- 新建文稿的标题默认是创建时的本地时间，颜色从六种里随机挑一种；用户可以随时改标题和颜色。标题不能为空，清空后恢复原标题。
- 新建后一个字都没写就切换到别的文稿，这篇空白文稿会被自动丢弃；空白文稿开着时再点「新建文稿」，仍回到这一篇。
- 打开应用时进入上次打开的文稿，光标在文末，可以直接输入；一篇文稿都没有时自动新建一篇。
- 正文是 Markdown 纯文本，方言为 GFM（表格、任务列表、删除线、围栏代码块），另支持 `==高亮==`。公式、Mermaid、脚注不支持。
- 侧栏按最后修改时间排序和分组（今天、昨天、本周早些时候、上周，再往前按月份），改标题或正文会让文稿排到最前，改颜色不会。
- 侧栏可以按颜色筛选：点一个颜色只看这种颜色的文稿，再点一下取消。
- 文稿保存在服务端，编辑后自动保存。同一篇文稿在多处同时编辑时，以最后一次保存为准。
- 离线时可以查看最近打开过的文稿，但不能编辑（规划中）。
- 删除文稿后可以立即撤销；未撤销的文稿 30 天后彻底清除。
- 文稿可以复制为 Markdown 或导出为 `.md` 文件。正文开头不是一级标题时，在最前面加上以文稿标题为内容的一级标题。

## 搜索

- 侧栏的搜索框按标题和正文搜索自己的文稿，回收站里的不出现。按回车开始搜索，清空搜索框就回到文稿列表。
- 多个词用空格隔开，每个词都要出现；不分大小写。
- 标题里有搜索词的排在前面，其余按最后修改时间。每条结果显示命中处所在的一行，搜索词标出颜色。
- 打开搜索结果时，正文里的搜索词标出颜色，光标停在第一处；开始编辑或清空搜索后颜色消失。
- 颜色筛选对搜索结果同样生效。

## 编辑

- 正文边写边显示排版效果：光标所在的行（或选中的行）显示 Markdown 源码，其他行只显示排版后的样子。
- 输入 `## ` 这样的标记后立即按标题、列表等显示。列表里回车自动续写下一项；在空的列表项上回车，嵌套的项退回上一级，顶层的项退出列表。Tab 和 Shift+Tab 调整列表层级。
- 待办前的复选框可以直接点击勾选，勾选状态写回正文。
- 链接要按住 Cmd（Mac）或 Ctrl 点击才打开，直接点击是把光标放进去编辑。
- `[文字]` 这类没有地址的方括号按普通文字显示。

## 图片

- 在正文里粘贴或拖入图片即可插入，图片单独占一行。支持 PNG、JPEG、GIF、WebP，单张不超过 10 MB。
- 上传完成前图片只是预览，上传失败时提示用户，正文不受影响。
- 图片只有上传者本人能看到。
- 图片从所有文稿（包括回收站里的）中删掉，并且上传已满 30 天后，会被彻底清除；在此之前撤销删除或撤销编辑，图片都还在。
- 导出的 `.md` 文件里图片仍指向本站，离开本站无法显示。

## 语音模式

- 只在用户切换到语音模式后可用；默认是键盘模式。
- 手机网页只保证能查看文稿，不提供语音模式。
- 按住按钮（电脑上也可以按住空格）说话，说话时在插入位置淡色显示识别中的文字，松手后定稿写入正文。
- 空格短按（不到 0.3 秒）照常打一个空格，长按才是说话。
- 转写结果插入光标处。没有点过正文时，光标在文末，效果等同于追加。
- 停顿较长时会自动断句，一次按住可以得到多句话，按顺序直接拼接。一次按住的结果作为一次修改，可以一次撤销。
- 刚写入的文字带一条文稿颜色的下划线，几秒后淡去。
- 识别时会去掉“嗯”“啊”这类口头语。
- 什么都没说或识别结果为空时，不插入任何内容。
- 识别失败（网络中断、超时、没有拿到最终结果）时提示用户：已经定稿的句子照常写入，还没定稿的半句丢弃。
- 一次按住最长 5 分钟，最后 30 秒显示剩余时间，到时自动结束并正常写入。
- 说话途中切换文稿或切回键盘模式，这次录音作废，不写入任何内容。
- 麦克风没有权限或找不到设备时给出提示。
- “换行”按钮另起一行，效果和回车相同。

## 整理

- 只在语音模式下出现。
- 只整理上次整理之后新转写、且没有被手动改过的文字，不会改动文稿的其他部分。转写的文字只要在中间被手动改过，就不再算待整理；撤销这次修改后又算回来。
- 整理保留全部信息和原意，不总结、不评论；去掉重复和说错后又改口的部分，修正同音错别字，并按内容组织成列表、待办或小节。新加的小节标题和文稿已有的标题层级衔接。
- 转写插在一行中间（例如列表项里）时，整理结果仍是这一行里的一段文字，不加结构。
- 被手写文字隔开的几段转写分别整理，各自替换原文，手写的文字不变。
- 指向「整理」按钮时，会标出将要整理的文字。
- 整理结果直接替换原文，一次整理可以一次撤销。
- 整理中不能说话，可以继续编辑；整理中被改动的那段不替换，并提示用户。整理中可以取消。
- 整理失败时提示原因，原文和待整理的状态都保留，可以再试。
- 没有待整理的内容时，按钮不可用，指向它时说明原因。

## 设备

- 安卓和 Mac 客户端（规划中）在系统浏览器里通过统一认证登录。登录后会看到一个确认页，列出设备名和当前账号；点「允许」，设备才算登录成功，点「取消」则这次登录作废。确认页 10 分钟内有效。
- 设备的登录和网页登录一样永久有效，直到在客户端退出，或在网页上吊销。在设备上登录不会让这个浏览器登录网页。
- 网页的用户菜单里可以查看所有已登录的设备：设备名、平台、登录日期，以及在线状态或最近使用时间。在线指 Mac 客户端正连着服务器。
- 吊销设备需要点两次确认，吊销后立即生效，不能撤销；要再用这台设备，需要重新登录。设备只能在客户端退出自己，不能吊销别的设备。

## 发送到电脑（规划中）

- 只在安卓客户端提供，网页不提供。
- 安卓端录音转写后，文字插入 Mac 当前光标所在的位置。
- 默认发送到最近有操作的那台 Mac，可以手动切换目标。
- 没有 Mac 在线时直接提示发送失败，不排队；文字保留在安卓端，可以复制。Mac 没有在 5 秒内确认插入、或者插入失败时，同样提示失败和原因。
- 发送的是识别原文，不经过整理，服务端不留存；安卓端保留最近几条记录，可以重发或复制。
